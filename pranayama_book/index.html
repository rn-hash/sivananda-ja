1. はじめに — DLSと本書の立場

本書は、DLS（ディヴァイン・ライフ・ソサエティ＝神聖生活協会・シヴァナンダ本人が1936年にリシケシュで創設した系統）の原典にのみ基づき、シヴァナンダ本人（1887–1963）が書籍の中で直接教えた呼吸法（プラーナーヤマ）のやり方を日本語に整理した実践書です。

呼称について — 本書で「本人の教えたやり方」と言うとき、それは弟子ヴィシュヌデーヴァーナンダが1959年にモントリオールで創設したセンター網（通称・センター系）の教え方ではなく、シヴァナンダ本人の著作（DLS/dlshq.org 無料頒布）に書かれた原文のことです。両者は組織的に無関係で、技法名や手順の細部が異なります（例: 本人の交互呼吸の正名は「スクハ・プールヴァカ」で「アヌローマ・ヴィローマ」という名は本人著作にない）。

底本は2冊ともDLSが無料公開している本人著作です。

  • 『呼吸法の科学』（The Science of Pranayama）— 呼吸法の理論と実技を体系立てて述べた本人の専門書。本書の主底本。
  • 『ハタ・ヨーガ』（Hatha Yoga・簡易版）— 同じ内容をより平易に述べ直した本人の入門書。写真的図版はこちらからも引用。

2. 実践の五条件と日常の心得（原典の規定）

五条件（『呼吸法の科学』第2章「実践に必要な五つのもの」）

  1. 良い場所 — 静かで美しく心地よい場所。専用の瞑想室が望ましく、無理なら部屋の一角を仕切る。師（グル）または崇拝する神（イシュタ・デヴァター）の写真を座法の前に置く。
  2. 適切な時期 — 食後すぐと空腹極まる時は避ける。朝（できれば早朝）が最良。
  3. 適量の食物 — 「ミターハーラ（適量食）」: 良質の浄らかな食物を胃の半分に、純水を4分の1に、残り4分の1を空けておく。
  4. 忍耐と持続 — 熱心さと安楽を伴う、根気強い反復。
  5. ナーディー（気の管）の浄化 — これが実践の第一段階「アーランバ（始発）」。

座る前の心得（同章・『ハタ・ヨーガ』）

  • 頭・首・胴を一直線に保つ（脊髄がまっすぐ伸びる）。
  • 座法（アーサナ）には4重の毛布の上に柔らかい白布を敷く。クサ草の座布団の上に鹿皮などを敷くのも原典の定め。
  • 先に用を足し（排便）、瞑想室に入る。
  • 食物は右鼻孔（ピンガラー＝太陽の管・温めて消化する）が働いている時に取る。
  • 息止め（クンバカ）を3分間行えれば、ナーディー浄化と心の安定、健康のためには十分（本人の実測的規定）。
原典の前提を一つ — 本人は「長時間の息止めには熟達した師の側にいること」「実践は漸進的に」と繰り返し述べています。本書の手順を試す際も、無理な息止めは決してしないこと（詳細は第8章の安全規則）。

3. スクハ・プールヴァカ（安楽先行呼吸法）— 本人の日常主技法

スクハ・プールヴァカ（Sukha Purvaka＝「安楽を先とする」呼吸法）は、本人が「朝夕の日常実践用」として最も重く置いた交互鼻孔呼吸法です。本人著作に「アヌローマ・ヴィローマ」という名はなく、この呼び名が正名です。

手順（『呼吸法の科学』「安楽先行呼吸法」の章・原文どおり）

  1. 蓮華座またはシッダーサナ（成就座）で座り、崇拝する神の写真の前で目を閉じる。
  2. 右手の親指で右鼻孔を塞ぎ、左鼻孔からごくゆっくり吸う。
  3. 左手の薬指と小指（原文の記述どおり右手で行う場合は薬指と小指）で左鼻孔も塞ぎ、快適に保てる限界まで息を止める。
  4. 親指を離し、右鼻孔からごくごくゆっくり吐く。 — ここまでで半分。
  5. 右鼻孔から吸う。
  6. 両鼻孔を塞いで同じだけ止め、左鼻孔からごくゆっくり吐く。
この6工程で1回。 朝20回・夕20回を原典の分量とする。徐々に増やす。

比例（1:4:2）と心唱

  • 比例は 吸1 : 止4 : 吐2。『ハタ・ヨーガ』では秒で「吸2秒・止8秒・吐4秒」と平易化。慣れれば数字を数えず、習慣で自然に保てる（原典第27–28条）。
  • 数え方の正本は OM（オーム）またはガーヤトリー・マントラを心で反復する。原典明文:「吸息・息止め・吐息の間、OMまたはガーヤトリーを心で反復せよ」。
  • 心の構え（バーヴァ）: 吸う気と共に神的資質（慈悲・愛・赦し・シャンティ＝平静・喜び＝ダイヴィ・サンパット）を入れ、吐く気と共に欲望・怒り・貪欲（アスリ・サンパット）を捨てる、と観じる。
「サーガルバ（マントラを心唱付きで行う）プラーナーヤーマは、付かない型の100倍の力がある。」— 本人の講話・『呼吸法の科学』関係箇所

効果（原典明文の要約）

すべての病を除き、ナーディーを浄化し、心を集中に安定させ、消化と食欲を増し、独身期の節制（ブラフマチャーリヤ）を保ち、脊髄底のチャクラ（ムーラダーラ＝基礎輪）に眠るクンダリニー（巻かれた霊力）を覚醒させる。

初歩の規定（本人明文） — 最初の数日は吸・吐のみで息止めなし。慣れてから息止めを10秒から始め、漸増。無理な止息は禁止。

4. カパーラバーティー（頭蓋光輝浄化法）

カパーラバーティー（Kapalabhati） — 「カパーラ」は頭蓋、「バーティ」は輝くこと。頭蓋を輝かせる行。ハタ・ヨーガの「六大浄化法（シャット・カルマ）」の一つとして位置づけられ、本人は「呼吸法の一章」として教えています。

手順（『呼吸法の科学』原文どおり）

  1. 蓮華座で座り、両手を膝に置き、目を閉じる。
  2. 吸息（プーラカ）は穏やか・緩慢・長く（ディールガ） — 腹筋の力を抜いて自然に吸う。
  3. 吐息（レーチャカ）を腹筋を強く内側へ押し込んで、速く・力強く叩き出す。これが主役。
  4. これを断続的に繰り返す。最初は1秒に1回のペース。慣れれば1秒に2回。
  5. 最初は朝1ラウンド・10回の叩き出しから。毎週10回ずつ増やし、最終的に1ラウンド120回まで。
息止め（クンバカ）は一切しないのがカパーラバーティーの原典的定義。
原典の注意 — 背中を丸めたり頭を垂れたりするのは望ましくない。頭と胴は真っ直ぐ。実践は力強く、汗が出るほど。カパーラバーティーに熟した者はバストリカーも容易にできる（本人明文）。

効果（原典明文の要約）

呼吸器系と鼻腔を浄化し、気管支の痙攣を除き喘息を緩和・根治へ向かわせ、肺尖部の酸素供給を整え、肺を発達させ、血中の不純物を追い出し、循環器・呼吸器系を大いに調える。結核菌の温床を与えない（本人の表現）。

5. 古典八古典型

本人は『ハタ・ヨーガ』で「ハタ・ヨーガの典籍には8種類の呼吸法が述べられている」と列挙しています。以下、原典の記述順。

  1. スーリヤ・ベーダ（スーリヤ・ベーダナ）
  2. ウジャーイー
  3. シートカリー
  4. シタリー
  5. バストリカー
  6. ブラマリー
  7. ムールチャー
  8. プラヴィニ

※ 書物により第8は「ケーヴァラ・クンバカ」とされることも本人は明記（第6章で扱う）。カパーラバーティーは八大古典型ではなく六大浄化法に属するが、「呼吸法の一変種」として本人が次章で教えている。

5.1 スーリヤ・ベーダ（右鼻孔呼吸法・スーリヤ・ベーダナ）

スーリヤ・ベーダ（Surya Bheda） — 「スーリヤ」は太陽＝右の管（ピンガラー）、「ベーダ（ベーダナ）」は貫くこと。吸うのも吐くのも太陽の管を通す行。

  1. 蓮華座またはシッダーサナで座り、目を閉じる。
  2. 右手の薬指と小指で左鼻孔を塞ぐ。
  3. 右鼻孔から、音を立てず、快適な限りゆっくり吸う。
  4. 親指で右鼻孔を塞ぎ、あごを胸に押し付けるジャーランダラ・バンダ（顎締め）を形成して息を止める。
  5. 汗が毛穴の根からにじみ出るまで止めるのが行の極点（原典明文）——最初は到底届かないので、漸進的に息止めの時間を伸ばす。
  6. 親指を離し、左鼻孔から、音もなくごくゆっくり吐く。
  7. 吸息・息止め・吐息の全体を通してOMを心で反復する（心の意味・趣を添えて）。

効果（原典明文の要約）

脳を浄化し、腸内の寄生虫と風（ヴァーユ＝気）の過剰から生じる病を破壊する。風の4つの悪を除き、関節リウマチ（ヴァータ）を治す。鼻炎・頭痛・諸種の神経痛を治す。老いと死を破壊し、クンダリニーの霊力を覚醒させ、身体の火を増す。

5.2 ウジャーイー（喉呼吸法）

ウジャーイー（Ujjayi） — 声門（のどの入り口）を半分閉じて、吸息時にさざ波のような均一な音を立てる呼吸法。

  1. 蓮華座またはシッダーサナで座り、口を閉じる。
  2. 両鼻孔から、なめらかで均一に、喉から心臓までの空間が満ちるまでゆっくり吸う。吸息中、声門の半閉により軽く均一な音が出る（その音は穏やかで均一な高さであること・連続していること）。
  3. 胸を拡げながら吸い、両鼻孔を塞いで快適な限界まで息を止める。
  4. 右鼻孔を親指で塞ぎながら左鼻孔からゆっくり吐く。原典は「代わりに両鼻孔からゆっくり吐いてもよい」とも明記。
  5. 歩きながら・立ちながらでも実践できる（原典明文）。

効果（原典明文の要約）

頭の熱を除き、胃の火を増し、喉の痰・喘息・肺結核・あらゆる肺の病を治す。心臓の病・酸素吸入不足から来る病を治し、水腫（腹水）を除く。「すべての業績はウジャーイー呼吸法によって成就する。老いと死を破壊するためにウジャーイーを行え」——本人の明文。

5.3 シートカリー（嘶き呼吸法）

シートカリー（Sitkari） — 舌の位置を整えて、口から「シー」と嘶くように吸う冷却呼吸法。

  1. 舌を折り畳み、舌先を上顎に当てる。舌が痛ければ唇の間に舌を挟んでもよい。
  2. 口を少し開け、口から「シーッ」という音を立ててゆっくり吸う（歯の両列を合わせて吸ってもよい）。
  3. 窒息感のない範囲で息を止め、両鼻孔からゆっくり吐く。
  4. 渇いた時に実践すれば、渇きは即座に緩和される（原典明文）。座りながら・歩きながらでも10回まで可。

効果（原典明文の要約）

実践者の美しさと身体の活力を増す。飢え・渇き・怠惰・眠気を除く。原典は誇張的な古代表現で「インドラ（神々の王）のような力を得て、無敵となる」とまで述べる（時代の烙印として受容）。

5.4 シタリー（筒舌呼吸法）

シタリー（Sitali） — 舌を筒状に丸め、蛇の呼吸を模倣する冷却呼吸法。

  1. 舌を縦に筒状に折り、唇から少し突き出す。
  2. 口から「シー（Si）」という嘶き音と共に空気を吸う。
  3. 快適に保てる限界まで息を止める。
  4. 両鼻孔からゆっくり吐く。
  5. 朝に15〜30回、日々繰り返す。蓮華座・シッダーサナ・金剛座（ヴァジラーサナ）でも、立ちながら・歩きながらでも可（原典明文）。

効果（原典明文の要約）

血液を浄化し、渇きを癒し飢えを鎮め、身体を冷やし、慢性消化不良（グルマ）・脾臓の炎症・諸種の慢性病・熱・肺結核・消化不良・胆汁の失調を破壊する。蛇の毒を含むあらゆる毒の悪影響を血から除く——「定期的に長く実践すれば、蛇の毒すら身体に影響しなくなる」と本人は述べる（古代の誇張表現）。

5.5 バストリカー（ふいご呼吸法）

バストリカー（Bhastrika） — サンスクリットで「ふいご（bellows）」。鍛冶屋がふいごを速く均一に吹かすように、息を速く動かす。「速く・力強い吐息の連続」が特徴。

  1. 蓮華座（原文はシッダーサナにも言及）で座り、身体・首・頭を真っ直ぐ。両手を膝に置き、口を閉じる。
  2. 吸う吐くを、鍛冶屋のふいごのように速く10回（『ハタ・ヨーガ』版は20回）繰り返す。胸を絶えず拡げ収縮させる。実践中にシーッという音が出る。声門を半分閉じてもよい。
  3. 規定回数の吸吐が終わったら、最後に深く吸える限り深い吸息を行い、快適な範囲で息を止め、ごくゆっくり吐き切る —— これで1ラウンド完了。
  4. ラウンドの間に数回の普通呼吸で小休止。
  5. 朝3ラウンド、夕にもう3ラウンドが原典の分量。多忙な者は朝1ラウンドでも十分（本人明文）。
  6. 全身を貫くOMを心で反復（原典明文）。
強力技法の注意（本人明文） — 眩暈を感じたら実践を中止し、普通呼吸を数回取る。眩暈が消えてから再開。夏は涼しい時間帯の朝のみ。極端に行ってはならない。長時間・強度に実践したい者は、実践前に朝食を消化の軽いもの（キチュリー）とし、浄腸（バスティまたは浣腸）を済ませる。

効果と位置づけ（原典明文の要約）

  • 喉の炎症を除き、胃の火を増し、痰を破壊し、鼻と胸の病を除き、喘息・肺結核を根絶する。食欲を与える。
  • 3つの結節（グランティ）——ブラフマ・ヴィシュヌ・ルドラの三結節——を破る。痰は「ブラフマ・ナーディー（＝スシュムナー、中心の管）の入り口の扉の閂」であり、バストリカーはそれを破ってクンダリニーを知らしめる。
  • 全クンバカ（息止め法）の中で最も有益。体温を保つ。ナーディーを大いに浄化する。
  • 構成上「カパーラバーティー＋ウジャーイーの合成」である（本人明文）——だから先にこの2つを練習するとバストリカーが容易になる。
  • 変種: 片鼻孔のみ使う型・左右交互に使う型がある。交互型は「20回の速い吸吐の後、右鼻孔から吸って止め左鼻孔から吐き、次いで左鼻孔から吸って止め右鼻孔から吐く」と原典に記載。

5.6 ブラマリー（蜂鳴呼吸法）

ブラマリー（Bhramari） — 「ブランマラ」は雌蜂。蜂の羽音のような音を立てる呼吸法。静かな夜の人目を避けた場所で実践するよう原典は定める。

  1. 蓮華座またはシッダーサナで座る。
  2. 両鼻孔から、雄蜂の羽音（チャラワーラ）を立てて速く吸う。
  3. 両鼻孔から、雌蜂の羽音（ハミング）を立てて速く吐く。
  4. 汗ばむまで続けてよい。終いに両鼻孔から吸い、快適な限界まで息を止め、ゆっくり吐く。
  5. 『ハタ・ヨーガ』は古典（ゲーランダ・サンヒター）版も併記: 両耳を親指で塞ぎ、両鼻孔から吸い、快適限界まで止め、両鼻孔から吐く。
実践の場（原典明文） — 外の音のない夜・人目を避けた場所で行う。この息止めの成就により、内なる神秘の音（アナーハタ音）が聞こえるようになる。この行の喜びは限りなく言いようがなく、成就すれば三昧（サマーディ）に成功する——本人の明文。

5.7 ムールチャー（失神呼吸法）

ムールチャー（Murchha） — 心を無意識化し安楽を与えるところからこの名がある息止め法。

  1. 座法で座り、深く吸う。
  2. あごを胸に押し付けるジャーランダラ・バンダ（顎締め）で息を止める。
  3. 失神しそうになるまで息を止め、それからゆっくり吐く。
原典の限定（明文） — 「しかし、これは多くの人には適さない（not suitable for many）」。息止めの期間は長期の漸進的練習の後に長くできる。止息中は自我（アートマン）に心を定める。『ハタ・ヨーガ』版:「自分の限界を超えて引き延ばしてはならない」。

5.8 プラヴィニ（水に浮く呼吸法）

プラヴィニ（Plavini） — この行の成就により蓮の葉のように水面に浮かべると伝えられる技法。胃に空気を飲み込む。

  1. 声門を閉じ、少しずつ空気を飲み込み、胃が膨らむまで満たす。
  2. 空気で満たされた胃を叩くと、特異な空洞音（鼓膜音）がする。
  3. 胃と肺を満たせば、長時間楽に水面に浮かべるとされる。
  4. 空気は、少しずつのげっぷをするか、ウッディヤーナ・バンダ（腹部挙上締め）によって出す。
本人の限定 — 「この行には熟達が必要。熟達者の実演を見るのが最も良い」。実践者は数日、空気を主食にして食物を断てると原典は述べる（伝統の誇張表現として記録）。

6. ケーヴァラ・クンバカ（自然息止め）

ケーヴァラ・クンバカ（Kevala Kumbhaka） — 息止めには2種ある。「サヒタ（伴う型）」は吸息・吐息に伴う息止め。「ケーヴァラ（単独の型）」はこれらを欠く、息止めのみの型。まずサヒタに熟達してからケーヴァラに挑む。

「吸息と吐息を捨てた後、楽に息を保つとき、それが絶対の息止め（ケーヴァラ）である。場所・時・数に条件づけられない息止めが、呼吸法の第4の型・絶対にして純粋な（ケーヴァラ・クンバカ）である。」— 『呼吸法の科学』（ヴァシシュタ・サンヒター＝古代の教典からの引用を含む）

手順と条件

  • 吸息と息止めなしに突然息を止める。止める長さは本人の望むだけ（原典明文）。
  • 息止め中は、心をあらゆる対象から引き、自我（アートマン）に固く定めるか、両眉間の空間（アージュニャー・チャクラ＝命令輪）に集中する。
  • 2〜3時間に1回行ってもよい。1日3回可。

位置づけ（原典明文）

ケーヴァラ・クンバカの実践により、王道ヨーガ（ラージャ・ヨーガ）の境地に至る。クンダリニーの知識が生じ、スシュムナー（中心の管）があらゆる障害から解き放たれる。ハタ・ヨーガの完成。「プラーナーヤマとケーヴァラを知る者が本当のヨーガ行者。この成就を得た者が三界で何を為し得ないことがあろうか」——本人の讃辞。

安全上の注記 — 本節は原典の記述の忠実な翻訳であり、無指導での長時間息止めを推奨するものではありません。熟達師の指導のもとで段階的に、が本人自身の繰り返しの定めです。

8. 安全規則（原典第29〜32条ほか・本人の明文）

  1. 疲れたら中止 — 実践中も後も、常に喜びと精神の爽快があること。実践から完全に活力回復した状態で出て行く。あまり多くの戒律で自分を縛らない（第29条）。
  2. 実践後30分は入浴しない — 30分休む。実践中に汗が出たら、タオルで拭かず手で撫でる。発汗時に冷たい隙間風に身体をさらさない（第30条）。
  3. 普段は無音でゆっくり — 吸う吐くとも常にごくゆっくり。音を立てない。ただしバストリカー・カパーラバーティー・シタリー・シートカリーでは、低い音程度なら立ててよい（第31条）。
  4. 2〜3分では効果なし — 最初は毎日最低15分を定期的に。毎日別の技法に飛び回るのは無意味。日々の実践は特定技法に固定し、それを高度に伸ばす。他の技法は時々の実践として添える（第32条）。
  5. 数える段階→数えない段階 — 初期の数日は数を数えて進歩を見る。上達すれば数えることで心を散らせない。肺が規定回数の終わりを教えてくれる（第28条）。
  6. 長時間の息止めには師の側で — 1〜3分の息止めは独習で可能。それ以上は、呼吸法を熟知した師の側にいること（本人の実測的規定）。
  7. 食後と空腹時は避ける — 用を足してから始める。
  8. 誰でも実践できる — 年齢を問わず実践すれば成就する。ただし読書するだけでは成就しない（本人明文）。
